# vendor-compare

Side-by-side vendor/tool comparison with a recommendation.

## Steps

1. Requirements first (must-have / nice-to-have) from the requester.
2. 3–5 vendors; for each: fit to must-haves, price (public or quoted), integration, data residency/security, references.
3. Note: new AI tools need the company's AI Tool Request SOP before use.
4. Recommend one with the main risk.

## Output

Line 1: recommendation + main reason. Table: vendor | must-haves met | price | security | risk.

## Quality checks

- Line 1 answers the ask.
- Every number and claim has a source link or query link.
- Under the word cap; no preamble or restating.
- Prices dated and sourced.
- Security/data residency covered.

## Pitfalls (learned)

- Comparing on features nobody required.
