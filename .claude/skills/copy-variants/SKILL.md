# copy-variants

Writes testable copy variants with one hypothesis per variant.

## Steps

1. Get the goal, audience, channel limits (characters) and language.
2. Write 3–6 variants, each testing ONE idea (urgency, social proof, benefit, loss aversion...).
3. Check claims are true and allowed (no guaranteed winnings, no misleading financial claims).
4. Recommend which 2 to test first and the metric.

## Output

Table: variant | text | idea tested | chars. Then 'Test first: A vs C, metric: <x>'.

## Quality checks

- Within channel character limits.
- No prohibited or misleading claims.
- Each variant tests one idea.

## Pitfalls (learned)

- Variants that differ in five ways at once — the test teaches nothing.
- Writing offer-dependent variants (bonus, expiry) without a confirmed offer — ask for offer, brand, payment method and character limits first, or mark those variants conditional (learned 2026-11-13 smoke test).
